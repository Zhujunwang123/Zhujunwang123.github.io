# Zhujun Wang — personal academic website

Static site (one `index.html` + `img/`). No build step.

## Deploy with GitHub Pages
1. Create a public repository named `<your-username>.github.io`
   (the site will live at `https://<your-username>.github.io`).
2. Upload everything in this folder (`index.html`, `img/`, `.nojekyll`, `README.md`) to the repository root.
3. In the repository: Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
4. Wait 1–2 minutes, then open the URL above.

To update later, replace `index.html` (and any changed images) and commit.
